## Architectural Decisions

### 1. Gap lifecycle — causal closure with artifact verification

A gap is an open loop. It stays open until the system produces a tangible artifact that provably makes the gap predicate false.

**"A job finished" is not closure. An artifact is closure.**

Three layers identified (from ChatGPT analysis, validated):
- Event layer (job dispatched, job completed) — activity, not truth
- Interpretation layer (gap detected, diagnosis generated) — modeling, not resolution
- State delta layer (something persists, old state invalidated) — the only layer that matters for closure

Truth floor principle: the system must always have minimum viable truth even when async paths fail. Qwen writes synchronous diagnosis at gap creation. Cannot be skipped.

Structural closure condition: a gap closes when the predicate that made it true becomes false AND a concrete artifact exists as evidence. Neither alone is sufficient.

Gap deduplication: two gaps with the same predicate identity (same table, field, op, scope) are the same gap. Before inserting, compute dedup_key, check for existing open gap. If exists: append evidence, increment recurrence_count, do NOT insert. This kills the cycle.

Full spec: `docs/gap-lifecycle.spec`

### 2. RAID routing was silently broken

`decide()` was never exported from `cortex/core/raid/index.js`. Only `_decide` (internal, wrong signature) was exported. Guardian called `_raid.decide()`, got `TypeError: _raid.decide is not a function`, silently caught it, and hardcoded `chatgpt` every time. RAID was running perfectly inside cortex's agent_calls loop but the guardian→RAID shortcut was completely broken since it was written.

Fix: added public `decide(prompt, opts)` wrapper that takes the simple call shape guardian uses, logs every decision to console so it's visible in autopilot.

### 3. RAID cluster classification — self-improving via Qwen

The old `_cluster()` was a static regex map. Words like "ship it" would miss. No way to improve without editing code.

New design:
- Layer 1: learned patterns from `raid-clusters.json` (Qwen-generated, weighted, persisted)
- Layer 2: baseline regex (always present, fallback)
- Qwen async classification runs after every cluster decision (non-blocking)
- When correction rate > 40% in recent samples, Mistral proposes new regex word groups
- New patterns written to disk, loaded on next boot
- System routes better with every use

### 4. Reflection engine — real contracts

Old reflection: scored decisions, opened gaps on streaks, stopped. Mistral never saw the gaps. Contracts table didn't exist.

New reflection:
- Streak threshold hit → gap created WITH predicate + artifact_requirement
- `reflection_contract` written to JAA simultaneously (§2.1)
- Guardian polls reflection_contracts every 30s, dispatches to Mistral via Ollama native
- `runReflectionPass` checks dispatched contracts each pass
- `verifyClosure` runs after Mistral responds — predicate AND artifact must both pass
- Contract stays open until real structural change is confirmed

### 5. Co-pilot v1.1 — real system operator

Old co-pilot: built context, returned stats blob. `_ollamaAgent` imported but never called. Displayed: "full narrated response not yet built, see docs/copilot.spec".

New co-pilot:
- Reads live system state before every response (gaps, jobs, health, providers)
- Qwen classifies intent (tool vs question vs action)
- Slash prefix → RAID-gated tool execution via /cli/exec
- Mistral generates reply with real system state as context
- Honest Ollama-offline fallback shows raw system state
- Full spec: `docs/copilot.spec`

### 6. Orchestrator — ui/agents hotswap watcher

`ui/agents/` was never in `SYSTEM_LOCAL_UI_DIRS`. ChatGPT and Mistral consoles never got hotswap events. Fixed with one line.

### 7. ChatGPT userscript — DOM selector fix + hard timeout

Root cause of the 300-job flood: `findResponseEl()` was returning null because ChatGPT's DOM changed. `checkStable` looped every 600ms forever. `startWatch` never completed. `GUARDIAN_COMPLETE` never sent. Same gaps re-dispatched every sweep.

Fix: 7 selector variants tried in order. 3-minute hard timeout — if ChatGPT doesn't respond, `GUARDIAN_ERROR` fires, job closes properly, gap loop can move on.

### 8. Mistral console — ui/agents/mistral/index.html

New agent console for local Ollama inference. No tab bridging, no NCP. Pings :11434 directly, shows installed models, stream progress, SEAM queue ladder. Ember accent (#ff7c38).
